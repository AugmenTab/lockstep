Known Python debt worth designing out from the start (not regression tests yet):
- branch-name collisions across runtime directories (open since dogfood-01);
- records older binaries cannot read because of strict decoding (dogfood-03);
- the human-wait wall clock counts against the run deadline (PY-REG-07);
- the basis check compares paths, not contents (PY-REG-07).

Process caveat (from the Python retros): dogfood-01…03 fixes were not test-first,
and the real-model behavior for PY-REG-04/07 was never exercised. v2 must not
cite these Python tests as proof of anything.
